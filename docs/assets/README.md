# Manuscript figures

These figures are reproduced from the accompanying CityDeploy-Bench manuscript. Their content and panel arrangement are unchanged. The repository uses PNG exports for direct browser display.

| Asset | Manuscript figure | Use |
| --- | --- | --- |
| [benchmark_overview.png](benchmark_overview.png) | Benchmark overview | Repository introduction |
| [scene_morphology.png](scene_morphology.png) | CityDeploy scene morphology and corpus composition | Benchmark description |
| [deployment_example.png](deployment_example.png) | Trafalgar Square scene and radio metrics | Physical-evaluation example |

The Trafalgar Square figure illustrates a **manually specified 11-TX deployment**. It is not the output of an optimized baseline and is not evidence that one method outperforms another. The corpus statistics shown in the morphology figure describe the manuscript's reference dataset, which is distributed separately from this source package.
